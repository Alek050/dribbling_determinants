# dribbling determinants
This GitHub repository aims to exemplify the data preprocessing and feature extraction used in the paper of Oonk et al (2023). Note that this code is purely to illustrate how the features were extracted. A more optimized software to load, preprocess, synchronize, and analyze soccer tracking and event data can be found in the [databallpy package](https://github.com/Alek050/databallpy). 

## How to use this repository
The main file in this pacakge is the notebooks. The first notebook is the [preprocessing and feature extraction notebook](https://github.com/Alek050/dribbling_determinants/blob/main/Example%20of%20preprocessing%20and%20feature%20extraction%20.ipynb). It illustrates the full process of data preprocessing and feature extraction. All the code that is used here is either via open source packages or provided in the `scripts` folder. Note that the data used for this example is from an open sourced tracking data dataset, which can be found [here](https://github.com/MatKempeGroningen/WCSF_SolutionRoom), since we are not allowed to share the used data of this project. In this dataset we miss the event data. The second notebook is for the [Multivariate Analysis](https://github.com/Alek050/dribbling_determinants/blob/main/Multivariate%20Analysis.ipynb). Thirdly, the training and performance of the classifiers can be found in the [Training the Models](https://github.com/Alek050/dribbling_determinants/blob/main/Training%20the%20Models.ipynb) notebook.
